# PDF Generation

The entry-point skill. It covers installing the module, the pages → rows → columns → components model, the recommended program skeleton (a `GetMaroto() core.Maroto` factory separated from output), which constructor shape to use, output options, every call that returns an error, an import cheat-sheet and a checklist to run before handing code over. It links to the other skills for the decisions it doesn't cover.
