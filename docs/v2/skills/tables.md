# PDF Tables

Patterns for tabular data such as invoices, statements and catalogs: planning column widths against the grid, shared cell styles, a manual-loop approach and a `list.Build` approach, zebra striping, grid lines, totals rows, repeating the header on every page, and variable-height cells for wrapping text.
